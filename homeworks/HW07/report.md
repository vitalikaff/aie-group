### 1.2 Dataset B

### 1.3 Dataset C

- Файл: `S07-hw-dataset-04.csv`
- Размер: ~1000 строк, 33 столбца

- Пропуски: есть в числовых признаках
- Подлости датасета: высокая размерность, пропуски, категориальные признаки

## 2. Protocol

Использовался единый честный unsupervised-протокол:
- числовые признаки: SimpleImputer(median) + StandardScaler
- категориальные признаки (dataset-04): SimpleImputer(most_frequent) + OneHotEncoder
- одинаковый препроцессинг применялся ко всем моделям одного датасета
- подбор гиперпараметров осуществлялся по silhouette score
- для DBSCAN метрики считались только на non-noise точках
- визуализация: PCA(2D) для лучшего решения

## 3. Models

Для **каждого** датасета сравнивались следующие модели:

- **KMeans**
  - диапазон k: 2–15
  - фиксированы random_state=42 и n_init=20
- **DBSCAN**
  - eps: от 0.3 до 2.0
  - min_samples: 5 и 10
  - анализировалась доля шума
- **AgglomerativeClustering**
  - linkage: ward, average
  - диапазон k: 2–15

## 4. Results

### 4.1 Dataset A

- Лучший метод: DBSCAN
- Причина: корректно восстанавливает нелинейную структуру
- Метрики: см. `metrics_summary.json`
- Доля шума: умеренная, интерпретируема

### 4.2 Dataset B

- Лучший метод: AgglomerativeClustering (average linkage)
- Причина: устойчив к разной плотности кластеров
- Метрики: см. `metrics_summary.json`

### 4.3 Dataset C

- Лучший метод: KMeans после масштабирования и one-hot encoding
- Причина: высокая размерность сглаживает эффект шума
- Метрики: см. `metrics_summary.json`

## 5. Analysis

### 5.1 Сравнение алгоритмов (важные наблюдения)

KMeans демонстрирует слабые результаты на нелинейных структурах и при наличии выбросов.
DBSCAN выигрывает на данных с плотностной структурой, но чувствителен к выбору eps.
Иерархическая кластеризация хорошо работает при разной плотности кластеров.

### 5.2 Устойчивость (обязательно для одного датасета)

Для dataset-02 выполнены 5 запусков KMeans с разными random_state.
Средний ARI между разбиениями оказался высоким (>0.9), что говорит об устойчивости решения.

### 5.3 Интерпретация кластеров

Кластеры интерпретировались через средние значения признаков.
В dataset-02 кластеры соответствуют различным нелинейным областям пространства.
В dataset-04 кластеры отражают комбинации числовых и категориальных профилей.

## 6. Conclusion

- Масштабирование критично для distance-based методов
- Silhouette не всегда совпадает с визуальной интерпретацией
- DBSCAN эффективен, но требует аккуратного подбора параметров
- PCA полезна для диагностики, но не для оценки качества
- Устойчивость — важная часть честного unsupervised-эксперимента
